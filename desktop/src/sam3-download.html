Download SAM 3

  1. Open facebook/sam3 on Hugging Face and accept Meta's SAM License. Access is granted by Meta, sometimes after a wait.
  2. Create a read token on your Hugging Face token page.
  3. Paste it here. The app downloads about 3.5 GB and checks every file's hash.
The token is used only for this download, sent only to huggingface.co, and never saved.
